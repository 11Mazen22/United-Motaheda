Each Edge Function is deployed individually via `supabase functions deploy <function-name>` (e.g. `supabase functions deploy admin-privileged-actions`). The notification worker requires the `NOTIFICATION_WORKER_SECRET` env var and authenticates callers via the `x-notification-worker-secret` header. Database indexes in `database/performance_indexes.sql` use `CREATE INDEX CONCURRENTLY` so they can be applied online; `supabase_indexes_v2.sql` provides a parallel set without `deleted_at` partial-index filters.
